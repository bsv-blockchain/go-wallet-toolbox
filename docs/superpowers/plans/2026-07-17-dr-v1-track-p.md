**Funder loop (replaces Phase 2+4 for non-sweep):**

```go
const insufficientBatchSize = 16

tiers := []wdk.UTXOStatus{wdk.UTXOStatusMined, wdk.UTXOStatusUnproven}
if includeSending { tiers = append(tiers, wdk.UTXOStatusSending) }
excluded := slices.Clone(forbiddenOutputIDs) // grows with each allocation

for !collector.IsFunded() {
    remaining := collector.remaining()
    if remaining <= 0 { break }
    allocated := false
    for _, tier := range tiers {
        u, err := repo.FindSmallestSufficientUTXOForUpdate(ctx, tx, userID, basket.Name, tier, uint64(remaining), excluded)
        // handle err; if u != nil: allocate, excluded = append(excluded, u.OutputID); allocated = true; break
        batch, err := repo.FindLargestInsufficientUTXOsForUpdate(ctx, tx, userID, basket.Name, tier, uint64(remaining), insufficientBatchSize, excluded)
        // allocate greedily from batch until IsFunded() or batch exhausted, appending each to excluded,
        // recomputing remaining each step; if any allocated: allocated = true; break out to outer loop
    }
    if !allocated { return nil, wdk.ErrNotEnoughFunds }
}
```

- [ ] `create.go`: extract the funding `Transaction(...)` call into a closure; retry loop:

```go
const maxFundingAttempts = 3
for attempt := 1; ; attempt++ {
    err = c.db.WithContext(ctx).Transaction(fundingClosure)
    if err == nil || !errors.Is(err, wdk.ErrUTXOContention) || attempt == maxFundingAttempts {
        break
    }
    select {
    case <-ctx.Done():
        return nil, fmt.Errorf("funding retry aborted: %w", ctx.Err())
    case <-time.After(backoffWithJitter(attempt, c.random)): // 25ms*attempt ±50%
    }
    c.logger.WarnContext(ctx, "retrying funding after UTXO contention", slog.Int("attempt", attempt))
}
```

  Reset per-attempt state (`funding`, `newOutputs`, `derivationPrefix` are assigned inside the closure — verify no cross-attempt leakage of appended slices; `newOutputs` must be rebuilt from scratch each attempt).
